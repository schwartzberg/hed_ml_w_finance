# CSCI E-278 — final project submission checklist

The syllabus describes a completed Jupyter/Colab notebook as the assessed final project. `notebooks/Finance_with_ML_CSCI_E278.ipynb` is the **primary deliverable**. Other files are supporting source code, tests and explanations.

The rubric has four categories, each worth 10 points. These are **review questions**, not a predicted grade:

- [ ] **Notebook organisation:** clear quantitative finance workflow, well-labelled sections, executes top-to-bottom.
- [ ] **Description of findings and outputs:** each table and figure is explained in plain English, including units, assumptions and contrary results.
- [ ] **Topics covered:** feature engineering, random forests, time-series testing, portfolio management, cost and risk measurement treated with appropriate depth.
- [ ] **Creative implementation:** original cross-sector prediction experiment, fair baselines and useful robustness checks.

Execution gate — **not yet satisfied in this copy**:

- [ ] Install dependencies in an internet-enabled Python/Jupyter or Colab runtime.
- [ ] Run the full notebook with genuine historical Yahoo Finance prices (not synthetic test data).
- [ ] Check the downloaded data cache and SHA-256 manifest.
- [ ] Verify the training/test date audit and all chart values.
- [ ] Review and interpret the actual out-of-sample results without retuning to improve them.
- [ ] Confirm all notebook cells run cleanly from a fresh runtime, and save the **executed** notebook.
- [ ] Include the course-required acknowledgement of AI assistance and any outside sources.
- [ ] Commit the executed notebook and permitted original project sources to GitHub.

Do **not** include copyrighted lecture slides, the syllabus, grading rubric or a fellow student's sample notebook in a public repository without written permission.
